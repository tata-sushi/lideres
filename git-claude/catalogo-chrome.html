Chrome da dashboard — referência

Esta página mostra o chrome padrão das dashboards do portal (referência: recrutamento.html): o header como barra de ferramentas, o seletor de abas (.tabs), as sub-abas (.dash-subtabs) e o footer fixo.

Clique nas abas acima para alternar. Use os botões Zoom−/Zoom+ no header (escalam tudo, menos o próprio header). O Atualizar recarrega mantendo a aba.

Header — barra de ferramentas

Logo à esquerda; botões .header-plus (28×28, carbon, ícone citric) empurrados à direita pelo margin-left:auto no primeiro botão. Ordem:

  • Início → menu central home
  • Voltar → history.back()
  • Atualizar → hardRefresh() (limpa cache/SW, recarrega na mesma aba) id=btn-hard-refresh
  • Zoom− / Zoom+ → zoomOut() / zoomIn() 0.7–1.6×
  • Fixar → pinNoApp() (oculto por padrão; o app mostra) id=btn-pin
  • Menu → openDrawer() (drawer lateral)

Padrão atual não tem .header-title nem chip de usuário no header — a identidade fica na aba Sobre / no drawer.

Aba — Agenda

Cada aba seta body[data-view] e marca o .tab-btn.active (fundo carbon, texto citric). O conteúdo de cada aba aparece/some por data-view.

A barra .tabs rola na horizontal quando as abas não cabem (sem barra de rolagem visível).

Aba — Vagas

Abas usam data-aba-id="<GOV_PAGE_ID>::<slug>" para o controle de acesso por líder/perfil (quem vê cada aba é definido no app). Ver skill controle-acesso-abas-botoes.

Aba — Entrevistas

Tipografia da aba: DM Mono 11px, peso 500, uppercase, letter-spacing:1.5px. Ativa = fundo --carbon + texto --citric.

Aba — Testes

O .tab-btn usa flex:1 0 auto; min-width:max-content — cada aba ocupa o mínimo necessário e a barra rola quando passa da largura da tela.

Aba — Analítico

Aba típica de tabela completa (ordenar/dimensionar). O padrão visual das tabelas está na skill dashboards-kpi-graficos.

Sub-abas (.dash-subtabs) — fonte: Entrevistas

Pílulas .dash-subtab centralizadas dentro de um card. Inativa = fundo #FDEAEA texto #7A1A1A (bordô); ativa = fundo #35383F texto #CFFF00.

Servem para trocar a fonte dos gráficos dentro de uma mesma aba (ex.: KPIs de Entrevistas × Testes), sem trocar de aba.
